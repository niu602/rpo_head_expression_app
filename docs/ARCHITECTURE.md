# RPO 机器人头部表情显示 APP - 技术架构设计

## 一、项目概述

**项目名称**：RPO Robot Expression Display
**运行平台**：Redmi Note 12 Turbo (Android 13+)
**开发语言**：Kotlin
**UI框架**：Jetpack Compose
**最低API**：API 33 (Android 13)
**目标帧率**：60fps
**响应延迟**：≤100ms

## 二、整体架构

采用分层架构设计，模块间低耦合高内聚：

```
┌─────────────────────────────────────────────────────────┐
│                    Presentation Layer                    │
│  ┌──────────────┐  ┌──────────────────────────────────┐ │
│  │  MainActivity │  │         Compose Canvas           │ │
│  └──────────────┘  └──────────────────────────────────┘ │
├─────────────────────────────────────────────────────────┤
│                      Core Layer                         │
│  ┌──────────────────┐  ┌──────────────────────────────┐ │
│  │ ExpressionManager│  │      AnimationRenderer       │ │
│  │    (状态机)       │  │        (表情绘制)             │ │
│  └──────────────────┘  └──────────────────────────────┘ │
├─────────────────────────────────────────────────────────┤
│                   Integration Layer                     │
│  ┌──────────────────┐  ┌──────────────┐  ┌────────────┐ │
│  │ CommunicationMgr │  │ BrightnessMgr│  │  AssetMgr  │ │
│  │   (TCP Socket)   │  │  (光照传感器) │  │  (资源加载)│ │
│  └──────────────────┘  └──────────────┘  └────────────┘ │
└─────────────────────────────────────────────────────────┘
```

## 三、模块详细设计

### 3.1 表情管理模块 (expression/)

**核心类**：`ExpressionManager`

**职责**：
- 表情状态机管理，基于优先级的状态抢占
- 6种基础表情状态维护
- 自动眨眼调度
- 临时表情自动回落
- 表情序列播放（Demo流程）
- 状态流(StateFlow)驱动UI更新

**状态优先级**：
```
说话(SPEAKING) > 识别中(RECOGNIZING) > 思考(THINKING) > 应答(RESPONSE) > 待机(IDLE)
眨眼(BLINK)为待机附属状态，不参与优先级竞争
```

**关键特性**：
- 协程驱动，60fps状态更新
- 150ms平滑过渡动画
- 支持强制切换和普通切换两种模式
- 线程安全的单例实现

### 3.2 动画渲染模块 (animation/)

**核心类**：`ExpressionRenderer` + `ExpressionCanvas`

**职责**：
- Jetpack Compose Canvas自定义绘制
- 6种表情的矢量绘制实现
- 基于进度参数的动画驱动
- 硬件加速路径绘制
- 路径缓存减少GC

**表情绘制实现**：
| 表情 | 视觉效果 | 动画参数 |
|------|----------|----------|
| 待机 | 圆形眼睛 + 微笑嘴 | 呼吸缩放 + 上下微动 |
| 眨眼 | 眼睛快速闭合 | 0~0.5闭合，0.5~1睁开 |
| 说话 | 圆形眼睛 + 圆形嘴 | 嘴部张合正弦波 |
| 思考 | 上视眼睛 + 省略号 | 三点渐显循环 |
| 识别中 | 扫描框 + 扫描线 | 扫描线上下移动 |
| 应答 | 弯月眼 + 大笑 + 对勾 | 对勾绘制动画 |

**性能优化**：
- Path对象复用，避免每帧创建
- 纯函数绘制，无副作用
- 利用Compose重组优化，仅状态变化时重绘

### 3.3 主控通信模块 (communication/)

**核心类**：`CommunicationManager`

**职责**：
- TCP Socket客户端与roboto_origin通信
- JSON指令序列化/反序列化
- 自动重连机制（3秒间隔）
- 心跳保活（2秒间隔）
- 设备状态上报
- 预留USB串口扩展接口

**连接参数**：
- 默认端口：8899
- 连接超时：5000ms
- TCP_NODELAY：开启（低延迟）
- KeepAlive：开启

### 3.4 亮度管理模块 (sensor/)

**核心类**：`BrightnessManager`

**职责**：
- 光照传感器数据采集
- 环境光到屏幕亮度映射
- 亮度平滑过渡（避免闪烁）
- 窗口级亮度调节

**亮度映射曲线**：
- <10lux（暗光）：30%亮度
- 10~500lux（室内）：30%~80%线性映射
- >500lux（亮光）：100%亮度

## 五、性能指标

| 指标 | 目标值 | 实现方式 |
|------|--------|----------|
| 表情切换延迟 | ≤100ms | TCP_NODELAY + 协程调度 + 无锁状态更新 |
| 渲染帧率 | 60fps | 硬件加速 + Path缓存 + Compose优化 |
| 内存占用 | <50MB | 矢量绘制无位图 + 对象复用 |
| CPU占用 | <10% | 协程挂起等待 + 低频率传感器采样 |
| 待机功耗 | <1%/h | 低帧率动画 + 屏幕亮度自适应 |

## 六、扩展设计

1. **表情资源扩展**：支持assets目录下的帧动画资源加载
2. **多设备适配**：基于屏幕宽度自动缩放绘制坐标
3. **串口通信**：预留UsbManager接口，支持USB OTG直连主控
4. **语音联动**：可扩展ASR模块直接对接
5. **人脸识别**：可扩展CameraX实现本地人脸识别
