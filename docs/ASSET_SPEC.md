# 表情素材设计规范

## 一、屏幕适配基准

**目标设备**：Redmi Note 12 Turbo
- 物理分辨率：2400 × 1080 像素
- 屏幕比例：20:9
- DPI：446 ppi
- 安装方向：竖屏（Portrait）

**设计基准**：
- 设计稿尺寸：1080 × 2400 像素
- 安全区域：上下各留100px边距
- 表情绘制区域：居中 1080 × 1080 正方形区域

## 三、帧动画素材规范（如使用位图序列）

### 3.1 文件格式

- **格式**：PNG（带透明通道）或 WebP（推荐，体积更小）
- **位深**：8位
- **色彩空间**：sRGB
- **透明通道**：必须有

### 3.2 帧率要求

| 表情类型 | 帧率 | 帧数 | 循环方式 |
|----------|------|------|----------|
| 待机微动 | 12fps | 24帧（2秒循环） | 前后循环 |
| 眨眼 | 24fps | 12帧（0.5秒） | 播完即停 |
| 说话口型 | 24fps | 16帧 | 循环播放 |
| 思考 | 10fps | 6帧 | 循环播放 |
| 识别扫描 | 30fps | 60帧（2秒） | 循环播放 |
| 应答反馈 | 30fps | 30帧（1秒） | 播完停在最后一帧 |

### 3.3 文件命名规则

```
{表情类型}_{帧序号}.png
```

**示例**：
- `idle_00.png` ~ `idle_23.png`
- `blink_00.png` ~ `blink_11.png`
- `speaking_00.png` ~ `speaking_15.png`
- `thinking_00.png` ~ `thinking_05.png`
- `recognizing_00.png` ~ `recognizing_59.png`
- `response_00.png` ~ `response_29.png`

### 3.4 目录结构

## 四、矢量绘制规范（当前实现方式）

当前版本使用代码矢量绘制，如需替换为美术素材，遵循以下规范：

### 4.1 眼睛设计规范

- 标准形状：正圆形
- 高光位置：左上30%偏移
- 发光半径：眼睛半径的1.5倍
- 眨眼时：高度从100%线性降到0再恢复

### 4.2 嘴巴设计规范

- 待机：向上弯曲弧线，弯曲度30%
- 说话：椭圆形，高度随音量变化
- 思考：水平直线
- 应答：大弧度微笑，弯曲度60%

### 4.3 过渡动画规范

- 表情切换过渡时长：150ms
- 过渡方式：线性插值
- 切换时不做复杂转场，直接淡入淡出
- 保证切换响应时间<100ms

## 五、性能优化建议

1. **优先使用矢量绘制**：代码绘制比位图序列内存占用小90%以上
2. **位图压缩**：使用WebP格式，质量80%即可
3. **尺寸控制**：单张PNG不超过200KB
4. **预加载**：APP启动时预加载下一帧，避免卡顿
5. **回收机制**：不使用的表情及时从内存释放
